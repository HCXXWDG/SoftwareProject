# 地图基础层测试说明

适用组件：`frontend/src/features/map/MapSurface.tsx`

## 自动化验证

在 `frontend` 目录执行：

```powershell
npm ci
npm test
npm run build
```

Vitest 覆盖：

- 高德 JS API 脚本单例、安全密钥配置、加载失败和 8 秒超时。
- 无 Key 时切换可交互的离线演示地图。
- bbox 顺序固定为 `west,south,east,north`，zoom 返回整数。
- 离线地图按钮/键盘缩放、键盘平移和视口回调。
- 热力点颜色、最低透明度 `0.18`、详情浮层和 Props 刷新。
- 热力数据变化不重建高德地图实例，卸载时销毁实例和监听器。

## 无 Key 演示

1. 确保 `frontend/.env.local` 不存在，或将两个高德变量留空。
2. 执行 `npm run dev`。
3. 将 `<MapSurface />` 通过成员 A 的 `mapSlot` 注入页面。
4. 确认左上角显示“离线演示地图”。
5. 验证鼠标拖动、滚轮、缩放按钮、方向键和加减键。
6. 点击热力点，确认显示压力、置信度、反馈数和主要情绪标签。

## 带 Key 验证

在被 `.gitignore` 忽略的 `frontend/.env.local` 中配置：

```dotenv
VITE_AMAP_JS_KEY=<浏览器端 Key>
VITE_AMAP_SECURITY_CODE=<安全密钥>
```

1. 为浏览器 Key 配置本地开发域名白名单。
2. 重启 Vite 开发服务器。
3. 确认左上角显示“高德地图”，浏览器控制台无 Key 或域名错误。
4. 拖动和缩放地图，确认热力点位置跟随更新且地图实例不闪烁。
5. 修改传入的 `heatmapCells`，确认仅覆盖层更新。

## 网络失败降级

1. 保留本地 Key 配置。
2. 在浏览器开发者工具中阻断 `webapi.amap.com`，然后刷新。
3. 确认加载失败或 8 秒超时后显示“离线演示地图”。
4. 确认离线地图仍可平移、缩放、点击热力点并产生视口回调。

## 安全要求

- 不提交 `.env.local`、真实 Key、安全密钥或包含凭据的截图。
- CI 只验证无 Key 降级路径。
- 凭据泄露或出现在聊天记录后应在高德控制台轮换。
