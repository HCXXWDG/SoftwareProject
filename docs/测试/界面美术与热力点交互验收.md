# 界面美术与热力点交互验收

## 视觉

统一奶白背景、森林绿主色、青柠强调色、系统中文字体、细边框和卡片间距。欢迎页保留自由选点与常用地点，增加原生 SVG 校园步道插画；路线预览突出起终点、距离与用时。地图工具栏、来源切换、路线卡片、反馈、趋势和历史采用一致的视觉层级。压力颜色仍保留低压绿、中压黄、高压红。

通勤组件始终保持在根片段中的同一位置，不因页面切换重新挂载。通过 CSS 排序降低普通通勤面板在地图页的视觉优先级；待确认的提交仍位于顶部，保留不确定写入的恢复入口。

## 热力点交互

- 光晕与触控中心分离：光晕按置信度透明，中心保持清楚；按钮至少 44×44px。
- 按下立即放大中心，选中后显示持续外圈；详情标明已选热力点，数据源和置信度保留原口径。
- 详情打开及关闭用 preventScroll 恢复焦点，避免页面突然跳到热力点或详情；Escape、Enter、Space 可用。
- 热力点起拖超过 8px 后平移底图并取消本次点击，不打开详情或长按反馈。真实高德通过反投影移动中心，离线地图通过现有中心状态平移；两者沿用校园范围限制。
- 仅热力点设置 touch-action:none，防止起拖时变成浏览器页面滚动；其余页面仍可滚动。非左键、非主触点不能启动拖动，其他触点的结束不打断主触点。
- 范围变化、来源切换和反馈面板打开时继续遵守既有查询取消、详情清理和数据来源隔离规则。

## 验证范围

582 项前端单元测试包括新增手势与地图适配器测试。浏览器验证包括320/390px的按下、选中、详情不跳屏、拖动后bbox变化、拖后键盘点击，以及浏览器原生触屏输入。独立后端全栈仍验证反馈刷新、快照、通勤幂等和跨页面恢复。地图界面截图用于视觉检查，不代替生产环境或真机触控验收。

美术及热力点交互版已构建并更新到独立“心途验收”应用。582项单元、49项完整浏览器回归通过；TypeScript、Vite/PWA、Android debug构建通过。浏览器触屏测试不替代用户真机手感验收；当前本机后端和USB通道仍属于验收环境。
