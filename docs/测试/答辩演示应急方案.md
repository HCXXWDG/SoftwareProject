# 答辩演示应急方案

## 演示前检查

1. 使用已验收的 `v1.0.0` Tag，不在现场临时切换开发分支。
2. 提前运行 Frontend、Backend、E2E 和 Full-stack E2E。
3. 准备两个浏览器窗口：真实高德模式和无 Key 离线模式。
4. 不在投影画面展示 `.env`、Key、Token 或数据库密码。

## 主演示链路

1. 打开热力图，点击热力点查看压力和反馈详情。
2. 展示最快路线与少心累路线，切换选中路线。
3. 长按地图，选择压力和原因并提交反馈。
4. 展示趋势面板和次日建议。
5. 打开 Swagger 或测试报告说明 API、PostGIS 与自动化测试。

## 故障切换

| 故障 | 现场处理 |
| --- | --- |
| 高德 Key 或网络失败 | 立即切换无 Key离线地图，继续地图交互和反馈演示 |
| PostGIS 无法启动 | 使用 Spring Boot demo Profile，保留完整前端链路 |
| 后端端口被占用 | 结束旧 Java 进程后重新启动，不现场修改代码 |
| 浏览器缓存异常 | 使用无痕窗口或刷新页面，不清空项目数据目录 |
| 在线演示不可恢复 | 展示验收截图、Playwright 报告和 GitHub CI 记录 |

## 答辩说明口径

- 离线模式是设计内的演示降级能力，不是临时伪造页面。
- Mock E2E 验证前端交互，Full-stack E2E 验证真实 API 链路，
  Testcontainers 验证 PostGIS。
- 高德浏览器 Key、安全密钥和服务端 Key 均不进入 Git。
