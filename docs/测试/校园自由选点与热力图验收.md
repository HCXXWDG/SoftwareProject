# 校园自由选点与热力图验收

## 行为

起终点保留五个常用地点作为快捷项，并可分别进入“地图选择起点/终点”。拖动地图将中心准星移到校区地图范围内的位置，再点“使用此位置作为起点/终点”。坐标沿用高德 GCJ-02，精确到小数点后六位；取消不会改变选择，确认后焦点回到入口。自定义端点与历史恢复保留实际坐标，路线查询提交所选坐标，不替换为最近快捷点。

范围沿用现有 CAMPUS.bounds（校区周边外扩矩形），不等同于精确校园围墙多边形。提交前检查范围与起终点是否重合，真实步行是否可达仍由后端高德接口决定。

热力图默认显式查询 REAL_ONLY，只展示当前视口近七天的真实反馈。空数组显示原因及提交入口；需要查看模拟效果时，显式切换“演示热力图”，查询 SIMULATED_ONLY。来源说明与地图内徽章持续标识模拟反馈，路线来源、压力评分和真实趋势不受图层切换影响。切换立即移除旧来源数据并取消过期请求，避免请求乱序混用。新增真实反馈保存成功后自动返回真实图层并刷新；重复回执不重复写入。

没有真实反馈时保留空热力图，不用模拟数据填充真实评分。热力点显示层高于路线交互层，路线重合处仍可打开热力详情。

## 验证

- 单元测试：任意点选择、取消保留、中心反投影、焦点恢复、参数范围、真实空结果、来源切换、迟到响应和失败、提交后切回真实。
- 浏览器：320/390px 自由选点、地图拖动、另一端保留、实际 compare 坐标、重载恢复，以及真实空图→模拟点→真实图的隔离。
- 独立 demo 后端全栈：初始真实结果为空，显式模拟结果有热力点，提交真实反馈后真实图层出现新点；通勤与幂等验证继续执行。集成测试须使用新启动的内存后端，避免上一轮反馈残留。
- Android：使用独立验收包测试已配置的真实高德。若采用 adb reverse 连接本机后端，设备重连后需恢复转发；USB 环境验收不代表独立部署已完成。

运行 frontend 下 npm test、npm run build、npm run test:e2e，以及对独立后端运行 npm run test:e2e:integration。密钥从本机配置注入，不写入源码或验收报告。

## 2026-10-23 本轮结果

单元测试 574/574、浏览器回归 45/45、独立 demo 后端全栈 4/4，通过 TypeScript、Vite/PWA 及 Android debug 构建。真机已安装独立验收包；用户完成任意端点选择并确认真实路线及热力图已显示。其自选坐标的后端真实高德请求亦返回 200（约 893 米、714 秒）。手机操作中曾因 USB 转发丢失连接失败，恢复转发后成功。抓取最终画面时用户已返回欢迎页，不能将该截图记为热力图视觉验收图片。
