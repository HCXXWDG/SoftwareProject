# 2026-10-23 最终优化复核

本轮范围是梁溪区「心途——通勤情绪地图」的交互、压力显示、通勤可靠性及运行边界。候选仍通过 PR #78 交由其他成员复核，不直接合并或发布。

## 已修复

| 问题与影响 | 最终行为 |
| --- | --- |
| 真实高德底图没有显式缩放控件；SDK 拦截冒泡事件可能使长按反馈失效 | 在线、离线共用放大、缩小、重置视野按钮，点击区域至少 44px；在捕获阶段观察长按，拖动、取消和多指操作取消长按；在线底图支持键盘移动与缩放 |
| 地图拖动时路线和热力图只在手势结束后对齐 | 移动和缩放中更新覆盖层投影；只在手势结束提交视口查询，避免逐帧发送热力请求 |
| 反馈框打开后位置不够明确，聚焦可能使手机页面跳动 | 标注地理反馈位置及经纬度，提交沿用打开时坐标；焦点恢复不滚动页面；弹窗保留地图底部归属信息的空间 |
| 单次 0/100 压力被 3 条虚拟中性先验压缩到约 38/62，蓝红难以拉开 | 地图显示实际反馈的时间加权均值，0 蓝、100 红；反馈数与置信度独立展示，低置信度提示证据有限。路线评分继续调用原先验平滑入口，评分版本与数值回归保持一致 |
| 手机粘滞 hover 使到达感受已选状态变淡、文字对比度下降 | 选中保持深绿底白字，并显示已选感受；全局基础 hover 降低优先级，减少覆盖组件状态 |
| 常用地点按钮偏小、相同起终点仅禁用却无原因 | 常用地点至少 44px 高，相同起终点给出关联原因；改善辅助文字对比度 |
| 自选地点真实路线成功后仍显示没有演示路线，易误判为失败 | 该提示仅出现在查询失败或没有候选时；恢复路线、重试按钮的清晰 hover 状态 |
| 长距离步行仍采用固定 30 分钟有效期，到达时可能无法首次完成通勤 | 按所选路线计算 `max(30 分钟, 预计耗时 + 15 分钟)`，不借用未选的慢路线延长窗口 |
| 保存成功后回执丢失，过期后重试无法找回记录 | 先按设备及操作号回读已存结果；同内容返回原回执，不同内容 409，跨设备隔离继续生效 |
| CORS 用 localhost 字符串前缀判断，可误接纳伪装域名 | 解析并精确校验本地协议及主机；保留显式来源白名单，拒绝主机后缀、用户信息和非法来源 |

## 仍需保留的运行条件

- 手机现有服务使用内存仓储。原 18083 进程及 USB `18080 → 18083` 映射保留，本轮不以重启清空已有 8 条真实反馈。新版后端在独立端口验证，当前手机后端不会因此自动升级。正式保留历史需配置 PostgreSQL/PostGIS，并安排现有临时数据的保留方案。
- 地图服务区域使用统一的梁溪区外包矩形，并非精确行政多边形围栏。
- `completedAt` 当前只有时间格式解析，没有未来、过旧或早于快照的业务范围校验；手机时钟错误可能使记录落在查询窗口之外。它不能延长快照有效期，幂等重放不会覆盖原时间。本轮未引入未经约定的时间阈值。
- 真实反馈样本仍少。颜色表达观测压力，不等于客观安全评级，低置信度及反馈来源必须保留；演示数据不计入真实通勤趋势。
- PR 尚需成员复核；本轮不修改保护规则、不批量合并其他成员工作。
