# Release v1.1.0 — 校园版与跨平台改造

**发布日期**：2026-06-30

## 概述

本次发布将"城市通勤情绪地图"改造为校园版，固定江南大学蠡湖校区场景，并新增 Android APK 和 Windows PWA 两种跨平台分发渠道。

## 新功能

### 校园三阶段流程
- 欢迎页 → 预设路线展示 → 校园地图，固定端点：学生公寓区 → 第一教学楼
- 用户只能选择最快/少心累路线，不可修改起终点
- 欢迎页零 API 请求，路线预览只调 compareRoutes，进入地图后才加载热力图和趋势

### 校园地图边界约束
- 高德模式：`limitBounds` + `zooms=[15,18]`，拖出校园自动回弹
- 离线模式：拖动、键盘平移、缩放统一 clamp 到校园边界
- 固定起点（绿）/终点（红）标记
- 长按反馈坐标位于校园边界内才有效

### Android（Capacitor 8）
- appId `com.jiangnan.course.commutemoodmap`，minSdk 24（Android 7）
- Release 签名构建（CI 生成 keystore）
- Capacitor 生命周期插件：SplashScreen、StatusBar、App
- `.env.android.example` 环境变量模板

### Windows PWA
- `vite-plugin-pwa` standalone 模式
- 192/512/maskable 图标
- Service Worker：`/api/**`、高德脚本、地图瓦片 NetworkOnly
- 应用外壳 precache，离线可启动欢迎页

### CI
- Android Build CI：debug + release APK 构建、签名、上传
- Android APK Verification：aapt2 静态验证 APK manifest 和 web assets
- 版本号校验步骤
- 移动端/校园边界/欢迎流程 E2E 测试

### 文档
- 生产环境 HTTPS 部署指南（Nginx/Caddy、SSL 证书、高德 Key 轮换）
- 跨平台发布检查清单

## 数据迁移
- Demo 热力点迁移到蠡湖校区 GCJ-02 坐标
- `V3__campus_demo_seed.sql` Flyway migration
- `MockRouteProvider` 改为比例插值生成候选路线

## 安全改进
- CORS 精确允许来源（无 `*`），支持 `APP_CORS_ORIGINS` 环境变量
- `android:allowBackup="false"`
- `network_security_config.xml` 生产域名强制系统证书
- `file_paths.xml` 路径限制

## 工程改进
- `minifyEnabled true` + `shrinkResources true`
- proguard-rules.pro 完整保留规则
- GitHub Actions 升级至最新稳定版
- `gradle.properties` 启用 parallel 和 caching
- `vite.config.ts` 添加 `base: "./"`

## 已知限制
- Release keystore 为 CI 自动生成（非正式签名），正式发布需替换为团队管理的 keystore
- 后端需部署到公网 HTTPS 才能支持真机和 PWA 生产使用
- 高德 Key 需在控制台绑定 Android SHA1 指纹和 Web 域名白名单

## 升级说明
- 数据库：自动执行 `V3__campus_demo_seed.sql`（不改写已有 migration）
- 前端：`npm ci && npm run build`
- Android：`npm run build:android` → `npx cap open android` → 构建签名 APK
